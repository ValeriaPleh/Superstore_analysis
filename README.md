# Superstore sales analysis
Учебный проект. Анализ данных о продажах на примере датасета Superstore Sales.<br>
Источник данных: https://www.kaggle.com/datasets/ishanshrivastava28/superstore-sales/data <br>
Проект выполнен на Python (pandas, matplotlib, SQLite) и SQL.<br>

## О проекте
CSV - файл содержит данные о заказах, клиентах, продажах онлайн магазина по различным категориям товаров, в разных городах и для различных сегментов покупателей.<br>
* Выполнена загрузка и очистка данных.<br>
* Для удобства работы с SQL-запросами данные разделены на три таблицы:  
    - Orders - информация о заказах;  
    - Customers - информация о клиентах;  
    - Products - информация о продуктах.<br>
* Выполнены SQl-запросы для решения поставленных задач. <br>
* Выполнена визуализация данных: графики продаж по категориям товаров, а также сумма продаж и прибыль компании по годам.<br>
### Задачи проекта
1. Посчитать сумму продаж по категориям товаров.
2. Определить ТОП-5 продаваемых товаров.
3. Определить убыточные товары в категории "Furniturе".
4. Определить среднюю стоимость заказа, общую сумму заказов и выручку по каждому из сегментов.
5. Посчитать сумму продаж и выручку по годам.
6. Определить города с наибольшей выручкой по продажам.
### Выводы
- Определены товары, продажи которых приносят компании наибольшую прибыль, а также 
убыточные позиции товаров.
- Определно, что сегменты клиентов Corporate и Home Office имеют наиболее высокий средний чек,
при этом наибольшая выручка обеспечивается сегментом Consumer, за счет суммарно бОльшего количества заказов.
- Определены города - лидеры по выручке (New York, Los Angeles, San Francisco и др.)
- Зафиксирован рост продаж, а также выручки компании по годам.
